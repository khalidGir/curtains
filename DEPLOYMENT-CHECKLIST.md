## Deployment Steps

### Step 1: Create Vercel Project

```bash
# From the project directory
vercel login
vercel init
# Select: "curtains" project name
# Framework: None (static site)
# Build command: (leave empty)
# Output directory: . (current)
```

### Step 2: Set Environment Variables

In Vercel dashboard → Settings → Environment Variables:

| Variable | Value | Environment |
|----------|-------|-------------|
| `STAFF_CALCULATOR_PIN` | *(your staff access code)* | Production, Preview |
| `HABIBA_PRICING_CONFIG` | *(JSON from pricing-admin)* | Production, Preview |

### Step 3: Generate Pricing Config

1. Open `pricing-admin.html` locally
2. Assign each fabric to a tier (A-F)
3. Click "Download private config"
4. Copy the JSON content
5. Paste as `HABIBA_PRICING_CONFIG` value in Vercel

### Step 4: Deploy

```bash
vercel --prod
```

### Step 5: Verify Deployment

1. Visit the deployed URL
2. Test all pages:
   - `/` (Habiba main)
   - `/catalog.html` (Fabric catalogue)
   - `/projects.html` (Projects)
   - `/staff.html` (Staff pricing)
   - `/ararat/` (Ararat partner)
3. Test staff pricing:
   - Enter staff code
   - Select a fabric
   - Enter dimensions
   - Verify price calculation

## Environment Variables Reference

### STAFF_CALCULATOR_PIN
- **Purpose:** Authentication code for staff pricing calculator
- **Format:** Numeric string (e.g., "1234")
- **Usage:** Staff enter this code to access pricing tool
- **Security:** Compared using timing-safe comparison

### HABIBA_PRICING_CONFIG
- **Purpose:** Server-side pricing rules and fabric tier assignments
- **Format:** JSON object with structure:
  ```json
  {
    "version": 1,
    "currency": "ETB",
    "tiers": { "A": 900, "B": 1200, ... },
    "fabricTiers": { "HB-101": "A", "HB-102": "B", ... },
    "rules": {
      "sheerRatePerMeter": 900,
      "fullnessPerLayer": 2.5,
      "fabricWidthCm": 280,
      ...
    }
  }
  ```
- **Usage:** Generated by `pricing-admin.html` tool
- **Security:** Never committed to git, stored only in Vercel

## Rollback Plan

If issues occur after deployment:

1. **Immediate rollback:**
   ```bash
   vercel rollback
   ```

2. **Environment variable issues:**
   - Check Vercel dashboard → Settings → Environment Variables
   - Ensure both variables are set correctly
   - Redeploy after fixing

3. **API issues:**
   - Check Vercel Functions logs
   - Verify `HABIBA_PRICING_CONFIG` is valid JSON
   - Verify `STAFF_CALCULATOR_PIN` is set
